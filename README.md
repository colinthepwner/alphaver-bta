# AlphaVer

Experience EXT 16.05_20 (Cypress) in Better than Adventure! 8.0.1.

## Install

1. Put the AlphaVer jar in your mods folder.
2. Download the Cypress client and put it anywhere in your game folder.

Cypress client download:
<https://archive.org/download/ext1605_20_client/ext1605_20_client.jar>

For multiplayer, use the same AlphaVer jar on the server and on every player's game.
